发件邮箱配置

用于发送邮箱验证码（注册 / 找回密码等）。可绑定你的自有域名使用内置邮箱服务，或手动配置 SMTP 账号。
发送方式：
首次使用（绑定自有域名，免费版 3000 封/月）：
① 在 resend.com 注册并登录；
② 左侧 Domains → Add Domain，填入你的域名（如 9dd.cc.cd），按页面提示复制 DNS 记录：DKIM（TXT）+ SPF（TXT）；
③ 到 Cloudflare 控制台 → 你的域名 → DNS → 记录 → 添加这两条，保存后回 Resend 点 Verify，等验证通过（几分钟～几小时）；
④ 在 Resend 的 API Keys 页面创建 Key（re_ 开头），填到下方即可用你的域名发信。
