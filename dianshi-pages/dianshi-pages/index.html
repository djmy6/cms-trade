部署到 Cloudflare Pages

  1. 进入 dash.cloudflare.com → Workers & Pages → 创建 → Pages。
  2. 上传本 dianshi-pages/ 目录（包含 index.html 与 dianshi.json），或连接 Git 仓库推送；无需构建命令。
  3. 部署完成后获得形如 https://<项目名>.pages.dev 的域名，把 域名/dianshi.json 填入 TVBox 订阅即可。
